Option 1: Full Automation (Recommended)
────────────────────────────────────────
Windows:  build_and_program.bat
Linux:    ./build_and_program.sh

Option 2: Step-by-Step
────────────────────────────────────────
Step 1:   vivado -mode batch -source create_vivado_project.tcl
Step 2:   vivado -mode batch -source run_complete_flow.tcl
Step 3:   vivado -mode batch -source program_fpga.tcl

Option 3: Vivado GUI
────────────────────────────────────────
1. Open Vivado
2. Source create_vivado_project.tcl
3. Run Synthesis → Implementation → Bitstream
4. Open Hardware Manager → Program Device
